#Project Overview
This application is a voice-driven tool that listens to microphone input in chunks and uses a local AI model (OpenAI Whisper) to transcribe speech to text. 

#how to run locally
python 3.10
FFmpeg: Required by the OpenAI Whisper library for audio processing.
Windows: ' winget install ffmpeg'.
Linux: 'sudo apt-get install ffmpeg'.
Mac: 'brew install ffmpeg'.

#Install dependencies:
pip install -r requirements.txt

#Usage
Run the main application:
python main.py
For Automated testing: pytest
