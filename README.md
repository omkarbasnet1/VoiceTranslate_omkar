## Project Overview
This application is a voice-driven tool that listens to microphone input in chunks and uses a local AI model (OpenAI Whisper) to transcribe speech to text. 

## how to run locally
1. **python 3.10**
2. **FFmpeg:** Required by the OpenAI Whisper library for audio processing.
  **Windows:** ' winget install ffmpeg'.
  **Linux:** 'sudo apt-get install ffmpeg'.
  **Mac**: 'brew install ffmpeg'.

### Install dependencies:
1. pip install -r requirements.txt

### Usage
1. Run the main application:
  python main.py
2. For Automated testing:
    pytest
